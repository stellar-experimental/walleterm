Your agent asks. 1Password signs.

walleterm is a small macOS signing companion for Stellar. Agents request signatures. Private keys never leave 1Password.

Install walleterm Read the source

How it works

One request goes out. One checked signature comes back.

  1. 01

    Your agent prepares the transaction

    It builds and inspects the transaction with the Stellar CLI, then computes its digest.

  2. 02

    1Password signs the digest

    walleterm sends the digest to the 1Password SSH agent. Approve on your Mac if asked.

  3. 03

    walleterm checks the signature

    It verifies the Ed25519 signature, then returns one JSON object to your agent.

Made for agents to read

Each command returns one JSON object. A failure returns a stable error code.

Skills ship for Claude Code, Codex, OpenCode, and Grok. It also runs as stellar walleterm.

$ walleterm sign < request.json
{
  "ok": true,
  "public_key": "GDX4…Q7MA",
  "digest": "5f1c9e…a04b",
  "signature": "9ad07e…c211",
  "verified": true
}

Boundaries

What it will and will not do.

Keys stay in 1Password
You create the Ed25519 key inside 1Password. walleterm never exports, prints, logs, or caches a private key.
Every signature is checked
walleterm verifies each signature against the public key before it returns it. It never retries a signature.
You review the transaction
The signer sees a digest, not an amount or a destination. Inspect the transaction before you sign it.
Websites stay on testnet
The website bridge accepts testnet transactions only. Use dedicated keys, not a shared SSH key.
macOS and Ed25519 today
walleterm needs the 1Password desktop app on a Mac. Passkey support is a separate, future task.

Websites

A website can ask, too.

Run walleterm tunnel. A testnet website connects with a QR code or an eight-digit code. Then it can request signatures from the key you pick.

4821 0937

  • Works once
  • Expires in five minutes
  • Testnet only

Install

Start on your Mac.

Turn on the SSH agent in the 1Password desktop app. Then run these commands. Homebrew installs everything else.

brew tap stellar-experimental/walleterm https://github.com/stellar-experimental/walleterm
brew install --cask stellar-experimental/walleterm/walleterm
npx skills add stellar-experimental/walleterm -g -s walleterm -s walleterm-site-bridge
walleterm list --human
