[warmly] Let's get 1Password ready for Walleterm.

First, open Settings, then Developer. Lots of people have the SSH agent turned off. [upbeat] Check the box to turn it on.

Next, create a vault for your key. Any name works, so pick whatever you like.

Now add the key. Choose New Item, then SSH Key. Select Add Private Key, and generate a new one. The default type is fine. Give it any name, then save.

[thoughtful] The agent can't see keys in a custom vault yet. So open the agent config file from the banner, and add the vault and the key name.

[calmly] One optional extra: the 1Password command line tool. You only need it to limit the tunnel to a single vault. The install command is on screen. Then turn on CLI integration in the Developer settings.

[upbeat] Finally, open a terminal and run walleterm list. Your key shows up. When a signature is requested, 1Password asks for approval. Look over the request, then approve it with Touch ID.

[warmly] That's it. You're all set.
