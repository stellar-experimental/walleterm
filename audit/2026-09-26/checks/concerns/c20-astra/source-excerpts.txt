1: # walleterm
2: 
3: A small macOS signing companion for agents using Stellar and 1Password.
4: 
5: `walleterm` lists public Ed25519 keys and signs 32-byte digests through the 1Password desktop SSH agent.
6: It verifies each signature before returning it. The Go binary has no third-party dependencies.
7: `walleterm tunnel` also lets a connected testnet website request signatures.
8: 
9: ## Install
10: 
11: Install Go, Bun 1.4.2 or later, cloudflared, the 1Password desktop app, and the Stellar CLI first.
12: Enable the 1Password SSH agent in the desktop app.
13: 
14: ```sh
15: brew install go oven-sh/bun/bun cloudflared
16: make install
17: make install-skill
18: walleterm --help
19: stellar walleterm --help
20: ```
21: 
22: `make install` installs the binary and `stellar-walleterm` executable alias into `~/.local/bin`.
23: Keep that directory on `PATH`, including in non-interactive agent shells.
24: Both commands work from any directory. They do not require a shell alias.
25: Run `make install` again after source changes to update the binary and bridge files together.
26: The installer prepares all dependencies before it switches the command to a complete version.
27: A failed build or Bun install preserves the previous command. Existing processes keep their original files.
28: Version directories stay under `~/.local/share/walleterm/releases` for running processes and rollback.
29: Use `make build` for a build under this checkout's `bin/` directory.

docs/INTERFACE.md:132-147
132: ## Runtime limits
133: 
134: - Use only `~/Library/Group Containers/2BUA8C4S2C.com.1password/t/agent.sock` on macOS.
135: - Do not expose a runtime socket override or use `SSH_AUTH_SOCK`.
136: - Verify socket type, owner, and restrictive permissions before connecting.
137: - Bound each response frame to 1 MiB and each identity list to 1024 entries.
138: - Use a 120-second absolute deadline for the full list-and-sign operation and pollable standard input.
139:   Signing input requires EOF. Regular input files finish normally; non-pollable streams may need a caller timeout.
140: - Reject invalid lengths, unsupported response types, invalid algorithms, and trailing data inside a response.
141: - Close connections on completion, failure, and timeout.
142: - Do not retry signing automatically.
143: - Inject a mock socket only through an internal test function.
144: 
145: ## Deliberate limits
146: 
147: The command signs a digest. It cannot determine that digest's network, amount, destination, or contract policy.
